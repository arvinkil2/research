# research
Kilambi Research — public archive of empirical research papers (research.kilambi.com)

## Publishing a new paper

Add the catalogue row to the table in `index.html`, the `paper-NN.html`
page, and the PDF under `papers/`, then publish with `publish_research.py`.
Do NOT hand-edit any paper count or the "papers · Month Year" line in
`index.html`: since 2026-11-05 both counts derive in the browser from the
catalogue rows themselves (the numbers in the static HTML are only the
no-JS fallback).
